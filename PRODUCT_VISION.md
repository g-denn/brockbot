# Brockbot

## Purpose

Help one person delegate focused local work to named AI teammates and review the result.

## First user

A person already using Codex locally who wants recurring roles such as researcher, writer, or project assistant.

## Product promise

Each teammate has a distinct local folder and a clear job. The user can send a task and source files, watch progress, inspect output, and continue the conversation.

## MVP boundary

Runs use the locally signed-in Codex CLI. Brockbot has no cloud computer, scheduling, external app connections, or shared team workspace. The local folder does not restrict Codex's file access. Agent output requires review.
